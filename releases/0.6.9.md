# OKF CLI and plugin 0.6.9

Use the feedback skill or `okf learn draft feature-request` to capture a defect, feature
request, guidance gap, or workflow lesson. Drafting works with collection disabled and after
successful commands. The skill ships a Markdown template and four fictional examples. It asks
authors to describe the goal, workaround, and desired outcome using invented data.

## Local collection and reporting

Counting is off by default. To opt in, run `okf learn enable` in a terminal and confirm.
The CLI counts qualifying outcomes from lint, validate, move, changeset apply, and ontology apply.
The report ranks affected invocations with a denominator per CLI version and command family.
The collector stores fixed identifiers and integer counts. Error messages, bundle paths, record
names, and authoring content stay out of the observer. Busy or unavailable stores can skip a sample.

Run `okf learn status` to see the per-user storage directory. Disable stops counting and keeps
the current data. Purge removes managed counts and drafts. User-exported copies remain at the
chosen destination.

## Drafts and export

Review and edit the private Markdown draft. Keep real product names, identifiers, and project
data out of the text. An export preview shows the complete draft, destination, and confirmation
digest. A confirmed export creates a new local file. Changes to the text or destination require
a fresh preview. This release has no network submission command.

## Compatibility and installation

Install CLI 0.6.9 for the learn commands. The plugin accepts stable CLI versions from 0.6.8
through the 0.6 series. On 0.6.8 the skill can prepare a draft from its bundled template.
Existing bundles, catalogs, and ontologies require no migration. The document specification
remains v0.2. Release archives cover Linux and macOS on x86-64 and ARM64.

Read the [capability design](https://github.com/briareus-io/okf/blob/v0.6.9/knowledge/contributing/design/local-feedback.md)
and the [feedback skill and examples](https://github.com/briareus-io/okf/tree/v0.6.9/plugins/okf/skills/feedback).
