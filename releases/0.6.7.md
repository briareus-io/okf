# OKF CLI and plugin 0.6.7

Install the CLI and plugin together. The plugin supports stable CLI versions
`>=0.6.7, <0.7.0`. Bundles retain the OKF v0.2 document format. Existing CI jobs
using warning-level lint gates should review the lifecycle diagnostic below.

## Concept size and CI settings

Three opt-in [concept size rules](../knowledge/commands/lint.md#concept-size) check body lines,
frontmatter lines, and line length. CI can use `OKF_SETTINGS_OVERRIDES` to select a
[partial lint settings file](../knowledge/reference/configuration.md#ci-lint-overrides).
For example, promote a bundle warning to an error while inheriting its line limit.

## Ontology authoring

Lint now reports conflicting top-level ontology `status` declarations, including in empty bundles.
Existing ontologies remain readable. Ontology edits and previews report the advisory without
changing write-gate decisions. CI using `--fail-on warn`, or using the default failure threshold
with `ontology_violation: error`, can fail on a previously passing bundle. Use a compatible
lifecycle enum or move domain workflow states to a custom field. See the
[lint reference](../knowledge/commands/lint.md#ontology-lifecycle-declarations).

## CI lint baselines

Lint can [compare findings](../knowledge/commands/lint.md#compare-lint-findings) against
a saved JSON baseline or a local workspace Git revision. CI can fail only on introduced or
worsened findings at its chosen severity. Use `--write-baseline` to explicitly accept the
current findings after review.

File and Git comparisons classify occurrences by stable finding identity and severity.
Use the same examination scope on both sides. Git comparison takes an exact local revision;
for a feature branch, pass its merge base with the target branch. An unavailable historical
dependency or an exhausted finding budget makes the comparison incomplete.

## YAML dependency

The workspace now uses `yaml_serde` 0.10.7 in place of the deprecated `serde_yaml` crate.
The published binaries continue to use YAML for bundle manifests, ontologies, and frontmatter.
