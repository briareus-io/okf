# OKF CLI and plugin 0.6.10

Set `OKF_FEEDBACK_DIR` to an absolute UTF-8 directory path to select where OKF stores private feedback drafts, collection consent, and counts. OKF uses that exact directory on every platform. Run `okf learn status` to see the selected directory. On Unix, an existing feedback directory must be private to its owner.

Leaving the variable unset keeps the platform default. Selecting another directory does not migrate existing feedback. Each directory has its own collection setting. No bundle or catalog migration is required.
