# OKF CLI and plugin 0.6.8

Install the CLI and plugin together. This plugin requires a stable CLI from 0.6.8 up to, but excluding, 0.7.0. The OKF document format remains v0.2.

Use `--no-align` on list, search, or backlinks for compact human tables. Columns, views, and projections can select `$trust_tier` and `$effective_status`. Unknown ontology field types report the canonical names and suggest common spellings.

Each skill now links to task-specific command examples and individual JSON record shapes. Machine consumers can discover the output modes of `show`, filtered relationship queries, drift summaries, and dangling-reference overrides in changeset previews. The schema command advertises both its header and its command records. Relationship pagination arguments are described as integers.

The verification workflow distinguishes typed bundle-root sources from document-relative references. The operational-bundle walkthrough refreshes its mutation context after editing the ontology.
