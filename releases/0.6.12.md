# OKF CLI and plugin 0.6.12

Load the rules and workflow instructions needed for a task with `okf bundle context --format agent`.
The output includes delivered instructions, summaries of available rules and workflows, declared
resources and outputs, effective inputs, and any missing required inputs.

## Read workflow context

For a workflow named `log-harvest` in a garden bundle, run:

```sh
okf bundle context garden --operation edit --workflow log-harvest --format agent
```

Check the process exit and final `Context: complete` line before acting. A workflow can still
list missing inputs after successful guidance delivery. Use JSON to inspect input types and
allowed enum values. For a planned mutation, add `--token` to the context request and pass the
receipt to the covered command. Check an existing receipt in a separate invocation.

Ordinary human output now shows workflow resource paths and reports common manifest metadata
and expansion commands once per bundle. On the garden feedback fixture, the previous compact
workflow context took 4,918 bytes. Agent output takes 469 bytes, including the 140 instruction
bytes, with either a 6-character or a 160-character bundle directory name.

## Declare saved queries per workflow

Add `uses_queries: [bed-tasks]` to a workflow to surface that saved query during an edit.
Use names defined in the same manifest under `settings.saved_queries`. An omitted or empty list
declares zero dependencies. Selecting multiple workflows combines their definitions, and an
unknown name fails manifest validation. Agent and compact context show the selected definitions.
An explicit `--operation query` exposes all saved queries and requests query coverage in a receipt.
Running a saved query still takes a separate command.

## Reuse an instruction file

Global guidance, rules, and workflows can share an `instructions_file`. The first record that
delivers the file carries the body. Later records identify that owner and retain their own role,
inputs, outputs, and resources. Delivery and mandatory byte totals count the shared body once
per bundle when applicable. A changed instruction file still invalidates a receipt.

## Upgrade CLI, skills, and JSON consumers

Install CLI 0.6.12 before adding `workflows.<id>.uses_queries` to a shared manifest. Upgrade every
reader of that bundle. CLI 0.6.11 recognizes saved queries but rejects the new workflow field.
The plugin retains its general stable CLI range of `>=0.6.8, <0.7.0`. For compatible older
manifests, agents can use JSON when agent format is unavailable. OKF documents remain v0.2.

Update consumers of `bundle context --json` to accept `content: "shared"` on guidance and
workflow records. Resolve `instructions_ref` by kind and ID against an earlier full record in
the same bundle and invocation. Use the referring record's instruction role to determine how
the body applies. The [bundle customization guide](https://github.com/briareus-io/okf/blob/v0.6.12/knowledge/guides/customize-a-bundle.md)
shows shared instructions and declared deliverables. The [saved-query guide](https://github.com/briareus-io/okf/blob/v0.6.12/knowledge/guides/save-and-run-queries.md)
walks through workflow-specific discovery.
